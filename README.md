# W2Full

W2Full è un'app Android nativa in Kotlin + Jetpack Compose per gestire rifornimenti, consumi e prezzi carburante usando i dataset open data ufficiali MIMIT.

Il progetto è in sviluppo per milestone e viene distribuito esclusivamente tramite APK / GitHub Releases.

La fonte di verità del progetto è [`PROJECT_SPEC.md`](./PROJECT_SPEC.md).
